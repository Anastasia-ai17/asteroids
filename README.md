# ☄️ Asteroids (Астероиды) - Классическая аркада на Pygame
Клон легендарной аркадной игры Asteroids. Игрок управляет космическим кораблем, уклоняется от астероидов и уничтожает их, чтобы набрать максимальное количество очков. Проект написан на Python с использованием библиотеки Pygame.

## ✨ Особенности игры
**Классический геймплей:** Управление кораблем, стрельба и уклонение от летящих астероидов.

**Физика и разбиение:** При попадании в крупные астероиды они разбиваются на более мелкие осколки.

**Бесконечное пространство:** При выходе за край экрана объекты появляются с противоположной стороны (тороидальное пространство).

**Логирование:** Игра ведет журнал событий (game_events.json), что позволяет отслеживать действия игрока.

## 🛠️ Технологии
**Язык:** Python (версия 3.10+)

**Библиотека:** Pygame (для графики и обработки ввода)

**Менеджер зависимостей:** uv (современный быстрый менеджер пакетов для Python)

## 🚀 Как запустить игру
Убедитесь, что у вас установлен uv (если нет — установите по инструкции на GitHub).

Откройте терминал и перейдите в папку с игрой (где находится файл main.py).

Запустите игру одной командой:

`uv run main.py`

*Команда uv run автоматически создаст виртуальное окружение, установит нужную версию Python и все зависимости из pyproject.toml, а затем запустит игру.*

## 🎮 Управление (Классика)
W / Стрелка вверх — движение вперед

A / Стрелка влево — поворот влево

D / Стрелка вправо — поворот вправо

S / Стрелка вниз — движение назад

Пробел (Space) — выстрел
